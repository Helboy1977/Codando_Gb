# Gabriel Sandre — Portfólio

Repositório com projetos desenvolvidos para praticar e demonstrar habilidades em desenvolvimento web e programação, com foco em vagas de estágio.

## Projetos

### 💰 [Controle de Gastos](./expense-tracker)

Aplicação full-stack para registrar e visualizar gastos por categoria, com API REST em Flask, persistência em SQLite e gráfico de distribuição no front-end.

`Python` `Flask` `SQLAlchemy` `JavaScript` `Chart.js` `pytest`

→ [Ver projeto](./expense-tracker) · [Como rodar](./expense-tracker/README.md#como-rodar-localmente)

### ⏱️ [Pomodoro Timer](./pomodoro_timer)

Cronômeto Pomodoro com interface gráfica (Tkinter), alternando entre sessões de foco e pausas, com aviso sonoro e contador de sessões.

`Python` `Tkinter`

→ [Ver projeto](./pomodoro_timer)
